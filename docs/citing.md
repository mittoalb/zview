# Citing zview

If zview helped your work, for example its images or renders appear in a
paper, a poster or a talk, please cite the software repository:

> Mittone, A. *zview: viewer and renderer for large 3D image volumes* (version
> 0.1.0). <https://github.com/mittoalb/zview>

```bibtex
@software{zview,
  author  = {Mittone, Alberto},
  title   = {zview: viewer and renderer for large 3D image volumes},
  url     = {https://github.com/mittoalb/zview},
  version = {0.1.0},
  year    = {2026}
}
```

The repository also has a [`CITATION.cff`](https://github.com/mittoalb/zview/blob/main/CITATION.cff)
file, so GitHub's **Cite this repository** button (in the *About* panel) gives
the same reference in APA and BibTeX. Please give the version you used: it is
printed in the Python package metadata (`pip show zview`).
